# UI prototypes

Put a few screenshots or wireframes of how the app should look here (usually 1–4). They are
blueprints, not exact designs: Claude follows them as closely as reasonable, but the built screens
don't have to be identical copies. Not every screen needs an image.

- Put the images directly in this folder, no subfolders. `.png`, `.jpg` and `.webp` all work.
- Name an image after the screen it shows, e.g. `login-page.png` or `dashboard.png`.
- When a feature touches the user interface, `/feature describe` and `/feature implement` look at
  these images. A feature that builds a screen with a matching image follows that image. All the
  images together set the overall look (colors, spacing, layout) for every other screen.
- The `/feature` actions never change these images. Replace or add one at any time, and commit it
  like any other file.
